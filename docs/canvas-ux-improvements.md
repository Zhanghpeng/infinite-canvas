# 画布体验优化记录（2026-10-20）

这一轮不是迁移、不是修 bug，是拿「高级设计师 + 内容生产」的工作方式反推：
人真正在画布上做片子时，卡住的不是生成能力，而是**找东西、排东西、判断能不能跑**这三件事。

## 1. 盘点：已有能力与真实缺口

先查了一遍现有交互，避免重复造轮子：

| 能力 | 现状 |
| --- | --- |
| 撤销 / 重做 | 有，50 步，节点与连线变更自动入栈（180ms 防抖） |
| 快捷键 | Ctrl+Z/Y/A/G/Shift+G/C/V、Delete、Esc |
| 右键菜单 | 有，含分组、拆批、截帧、复制等 |
| 小地图 / 定位节点 | 有（Minimap、`focusNode`） |
| 框选、多选 | 有，且排除折叠组成员与锁定节点 |
| 对齐参考线 | 有，但只在**拖拽时吸附** |
| **视图适配** | **缺**：内容一多，只能靠滚轮找 |
| **批量对齐 / 分布** | **缺**：多选后没有排齐手段 |
| **空画布引导** | **缺**：新项目是一片空白网格 |
| **分段编辑的工作流前置校验** | **缺**：渠道不匹配要等生成失败才知道 |

后四项是本轮补的。

## 2. 视图适配：Shift+1 / Shift+2

- `Shift+1` 适配全部内容，`Shift+2` 适配选中内容，缩放控件也有「适配全部」按钮。
- 用 `event.code === "Digit1"/"Digit2"` 判定，不用 `event.key`：Shift+1 在多数布局下
  `key` 是 `"!"`，按 key 判会失效。
- 计算包围盒时**跳过折叠分组的成员**。它们不可见，算进去只会在画面里留一圈莫名空白。
- 缩放上限 1.2：单个节点适配时不要放大到糊。
- 顺手抽了 `animateToViewport`，`focusNode` 改为复用 —— 定位节点与适配视图现在
  是同一套 450ms / easeOutCubic，跳转手感一致。

## 3. 批量对齐与等间距分布

多选 ≥2 个节点时，选集正上方浮出排版工具条（贴顶放不下会翻到下方）。
位置由世界坐标换算到屏幕坐标，**不放进世界层** —— 否则缩到 20% 时按钮也跟着缩成 10 像素。

### 3.1 基准是「选集包围盒」

与 Figma 的 Align to selection 一致：框选一片素材点左对齐，是靠到这片区域的左边界，
而不是画布原点。只动目标轴，另一个轴原样保留。

### 3.2 分布用等间距，不是等中心

一排宽窄不一的素材，视觉上要的是**留白一致**；等中心会让宽窄不一的节点看起来疏密不均。

首尾两个节点钉死不动，中间按 `gap = (总跨度 − 总尺寸) / (n − 1)` 排开。
例外：用户已经把节点叠在一起时 `gap < 0`，此时退回等中心分布 ——
负间距会让它们穿模，不如退一步。

### 3.3 与其它规则的衔接

- **锁定节点不参与，也不被移动**，与框选、批量删除的口径一致。
- 没有可动的东西时返回 `null`：不写历史、不刷 UI，避免误触产生一堆空历史。
- 组框参与排版后同步成员归属（`syncGroupMembershipAfterTransform`），
  与拖拽组框的行为一致。
- 3 个以上才能分布，两个节点之间没有可分布的空间，按钮置灰并给出原因。

## 4. 时间轴渠道校验：局部重绘 / 角色替换能不能跑在当前工作流上

结论：**能，但取决于渠道里配的是哪类工作流。**

| 工作流类目 | 参考视频 | 参考图 | 分段重绘 / 角色替换 |
| --- | --- | --- | --- |
| `omniVideo`（全能参考） | 接受 | 多张 | ✅ 可用 |
| `frameVideo`（首尾帧） | **不接受** | 首帧 / 尾帧槽位 | ❌ 提交必被拒 |

分段链路必须把「原片该段」作为**参考视频**送进去，所以只能走 `omniVideo`。
之前用户配了首尾帧工作流再打开时间轴，会在提交后才收到拒绝，白等一轮。

现在打开时间轴前先判定：工作流类目是 `frameVideo`，或模型名含 `frame` / `首尾帧`，
就弹出说明并给两个选择 ——「先去切换」或「仍然打开」。

补充：MiniMax 那条 API 路径本身不支持长视频，所以长片一定要分段；
分段后每段（默认 ≤6s）走的是同一个 `omniVideo` 工作流，不需要额外配置。

## 5. 空画布起手引导

新建项目打开是一整片空白网格 + 一圈工具栏，第一次用不知道能干什么。
改为居中引导卡：一句「把素材拖进来，或者让 AI 起手」+ 两个入口
（上传素材 / 让 AI 起手），并说明选中节点后能接下游、局部重绘、角色替换。

实现细节：容器 `pointer-events-none`、卡片单独放开，拖拽事件照常冒泡到画布根节点，
不会因为卡片挡住中间区域就丢素材。

## 7. 后续可做

1. 对齐 / 分布给快捷键（Figma 的 Alt+A 系），目前只能点工具条。
2. 统一尺寸（等宽 / 等高 / 等面积）与「吸附到网格」。
3. 节点级生成历史：同一节点多次生成的结果可回看切换，不必担心被覆盖。
4. 画布大纲 / 搜索：节点数过百后，光靠小地图仍然难找。
